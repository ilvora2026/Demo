# ILVORA Workforce — Managing Director Prototype v0.3

## Role 1 implementation
- Combined organisation overview with individual branch selector.
- Branch selection for Head Office, Neelambari Hospital, and ILVORA Health Clinic.
- Financial snapshot summary displayed first.
- Detailed financial report panel opens only when selected.
- MD role has full organisation-wide visibility in the prototype UI.
- Responsive layout.

## Run
Extract ZIP and open `index.html` in a modern browser.

## GitHub prototype
Upload `index.html` to a GitHub repository root. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Important
All displayed values are illustrative sample data. No login, database, API, real payroll, or real financial calculations are connected. Do not enter real employee information. This prototype is not a secure production system; backend role enforcement and audit logging will be implemented during the later integration phase.
