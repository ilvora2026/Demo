ILVORA Workforce – Head Office Admin Panel
Service 3: Attendance Governance & Correction Approval – Prototype v1

Open index.html in a modern browser.

Included:
- Central attendance correction request queue across three branches
- Branch/status/search filters
- Review of employee, current punch, requested punch, reason and evidence reference
- Approve, reject or return for clarification
- Mandatory reason for return/rejection
- Payroll-closed correction handling concept with adjustment reference
- Branch attendance exception overview
- Approval safeguards and audit governance notes

Important:
All data is illustrative and all actions run only in the browser. No live attendance database, real evidence storage, notifications, payroll integration, authentication or immutable audit log is connected. Production must enforce Head Office approval server-side, prevent requester self-approval, preserve original punch records, and create a payroll adjustment workflow for closed periods. Attendance Operators cannot edit punches or submit formal correction requests.
