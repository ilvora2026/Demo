ILVORA Workforce – Branch Admin / HR Service 8
Requests & Helpdesk Management – Prototype v1

Open index.html in a modern browser.

Features:
- Employee request register with search and status filter
- Create ticket linked to Employee ID
- HR/employment, salary/payslip, certificates, ID cards, profile corrections, IT, equipment, facilities and other categories
- Priority levels and suggested responsible teams
- Assignment, officer, status, progress notes and resolution reference
- Overdue/high-priority dashboard indicators (illustrative)
- Reports, print and CSV export
- Physical filing register

Important limitations:
- Fictional sample tickets only.
- Demo records and changes live only in browser memory and reset on refresh.
- Attachment selection records filename only; file bytes are not uploaded.
- No real login, role permissions, database, SLA engine, email/push notifications, employee portal connection or secure attachment storage.
- Production must add server-side ticket IDs, branch scoping, access controls, assignment rules, SLA timers, reminders/escalations, employee notifications, immutable audit trail and secure attachment scanning/storage.
- Payroll and employee records must be visible only to specifically authorised roles.
- Physical filing and digital retention must follow approved HR/legal records schedule.
