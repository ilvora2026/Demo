ILVORA WORKFORCE
Head Office Admin Panel – Service 5: Duty Roster & Shift Governance
Prototype v1

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome or Edge recommended).
3. Use the tabs to review submissions, preview the roster calendar, generate reports, and inspect revision history.
4. Sample approve/return actions update only the browser demo state.

INCLUDED
- Cross-branch roster submission queue for Head Office – Kochi, Neelambari Hospital – Thamarakulam, and ILVORA Health Clinic – Kottarakkara.
- Pending HO review, returned, approved and published statuses.
- Review details; approve or return with reason.
- Sample overlap/uncovered duty flags.
- Monthly roster calendar preview.
- Detailed and brief branch-wise/consolidated reports.
- CSV export and browser print / Save as PDF.
- Revision history and print/filing register metadata capture.
- Digital retention schedule: detailed roster eligible for deletion after the 15th of the following month; brief summary retained 3 years; legal/audit/investigation/regulatory holds pause deletion.

IMPORTANT LIMITATIONS
This is a front-end demonstration only. It does not connect to Cloudflare D1, GitHub, a live workforce database, real user accounts, role permissions, real approval workflows, scheduled deletion, notifications, or secure file storage. All sample records and approval changes are local demo data and may reset when the page is refreshed.
Head Office reviews and approves/returns roster versions; Branch Admin/HR remains responsible for creating and correcting assignments. The Head Office prototype does not silently edit shift allocations.
Production implementation must include server-side permission checks, version locking, immutable audit logs, validation of overlaps and uncovered shifts, secure backups, approved retention controls, and a legally reviewed physical-record schedule.
