Employee contact & login details

Login username is always the employee's existing Employee ID. Do not create a duplicate employee account.

First login workflow

  1. Temporary password sent to registered contact channel.
  2. Employee signs in using Employee ID and temporary password.
  3. System forces a password change before dashboard access.
  4. Employee's own password is used for subsequent logins.
Production: temporary password must be one-time, short-lived, rate-limited and securely hashed. Do not display it to the Head Office Admin.

Head Office password reset desk

Employees must contact Head Office. The Head Office Admin reviews identity, employment status and current access authorisation before issuing a reset.

Reset rules

  • Only Head Office Admin can initiate this reset workflow.
  • Confirm employee identity using approved verification steps.
  • Confirm employment status and current Branch Admin / HR authorisation.
  • Send a new temporary password to registered mobile/email.
  • Invalidate old sessions and temporary credentials.
  • Force password reset at next login.
Do not send temporary passwords to a newly supplied or unverified contact number/email.

Employment / position change review

Automatic access rules

  • Approved termination: revoke access effective immediately or on the approved effective date.
  • Approved resignation: schedule revocation at the end of the recorded last working day.
  • Position change: remove the Branch Admin / HR role if the new position is not eligible.
  • Branch transfer: replace old branch scope with approved new branch scope from the effective date.
  • Authorisation withdrawal: revoke dashboard permissions and active sessions.
Employee's core account and historical employment, attendance, payroll and leave records are retained. Only the relevant dashboard access is removed.
