ILVORA Workforce – Branch Admin / HR Service 5
Duty Roster & Shift Management – Prototype v2

Open index.html in a modern browser.

Roster retention policy added:
1. Detailed digital roster: print and file the detailed monthly roster. Automatically delete the detailed digital roster after the 15th of the following month.
2. Brief roster summary: retain for 3 years, then automatically delete at the end of its retention period.
3. Legal, audit, investigation or regulatory holds pause deletion.
4. Physical printed records have a separate approved retention and secure-destruction schedule. Printing does not itself authorise digital deletion.

Other included features:
- Month, week, day and staff-wise views
- Branch selector (demo)
- Select staff and allocate shifts to selected dates
- Morning, evening, night, custom and weekly-off allocation
- Exact start/end time with 30-minute interval validation
- Basic same-day overlapping shift validation
- Daily timeline and staff-wise roster
- Print and CSV export

Important limitations:
- All sample staff and shifts are fictional.
- Data is stored only in the current browser page memory; refreshing resets changes.
- Retention policy is displayed as a requirement only. No automatic deletion runs in this front-end demo.
- Production requires scheduled server-side retention jobs, date/period-based retention metadata, reminder notifications, print/filing register, immutable audit logs and legal-hold checks before deletion.
- No real login, branch permission enforcement, database, notifications, employee app sync or payroll integration.
- Production must add server-side conflict validation, rest-period rules, leave conflict checks, audit history, approval/versioning and secure authentication.
