Roster records & retention

Detailed roster: Print and file the detailed roster for the month. The detailed digital roster is scheduled for automatic deletion after the 15th of the following month.

Brief roster summary: Retain only the brief summary for 3 years, then automatically delete it when its retention period expires.

Safeguards: Legal, audit, investigation or regulatory holds pause deletion. Physical printed records follow a separate approved retention and secure-destruction schedule. Printing does not itself authorise digital deletion.

Production requires scheduled server-side deletion, reminders, a print/filing register, retention timestamps and immutable audit logs.
