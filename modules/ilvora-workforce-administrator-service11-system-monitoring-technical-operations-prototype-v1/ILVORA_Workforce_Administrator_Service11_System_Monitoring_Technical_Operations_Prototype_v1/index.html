Technical Actions & Authorisation

Routine operational actions

Review logs, retry safe failed jobs, verify service status and raise incidents where authorised. Each action should record actor, time, scope and result.

Restricted infrastructure actions

Database deletion, schema migrations, production secret changes, storage purge, restore-overwrite and disabling critical services require restricted technical access, documented approval, backup/rollback plan and audit log.

Administrator

Monitors service health, reviews operational exceptions and coordinates authorised support. No implicit unrestricted database or infrastructure access.

Head Office Admin / Managing Director

Head Office Admin continues branch administration. Managing Director receives executive-level incident and availability reporting; neither role should bypass technical safeguards.

Security reminder: Never display or store API keys, database credentials, passwords, OTPs, access tokens or full sensitive employee records in monitoring logs. Apply redaction, retention limits and least-privilege access.
