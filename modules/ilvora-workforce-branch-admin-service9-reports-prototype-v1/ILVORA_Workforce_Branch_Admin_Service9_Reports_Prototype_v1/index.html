Head Office reporting

Head Office Admin can access consolidated reports across authorised branches, compare branch-level indicators and export a combined summary.

Branch Admin / HR can view and export only their assigned branch data. Payroll attendance summary is read-only and does not grant salary access.

Prototype and governance note: All figures are sample data. This front-end does not connect to a live database, enforce real permissions, generate true PDF/Excel files, or run scheduled retention jobs. Production implementation requires role-based server authorisation, audited report queries, secure exports, data minimisation and legal-approved retention rules. Complaint reports must remain aggregate-only and must not expose confidential case details.
