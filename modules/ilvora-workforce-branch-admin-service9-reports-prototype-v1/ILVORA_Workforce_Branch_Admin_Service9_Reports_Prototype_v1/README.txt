ILVORA Workforce – Branch Admin / HR Service 9
Branch Reports & Analytics – Prototype v1

Open index.html in a modern browser.

Included:
- Branch, date-range and department filter interface
- Workforce, attendance, leave and helpdesk KPI cards
- Attendance and shift coverage indicators
- Department-wise employee strength
- Attendance, employee, leave, roster, document, grievance, helpdesk, payroll-attendance and compliance report catalogue
- Print and demo CSV export
- Head Office consolidated reporting concept with branch-scoped access

Important:
This is a front-end demonstration using illustrative data only. It is not connected to Cloudflare D1 or any live backend. Authentication, server-side role enforcement, live report queries, secure PDF/Excel generation, scheduled retention jobs and audit logging must be implemented before production use. Complaint reports are aggregate-only by design.
