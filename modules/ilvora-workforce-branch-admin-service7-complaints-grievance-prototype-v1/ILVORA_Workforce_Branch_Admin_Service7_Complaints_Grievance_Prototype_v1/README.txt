ILVORA Workforce – Branch Admin / HR Service 7
Complaints & Grievance Management – Prototype v1

Open index.html in a modern browser.

Features:
- Complaint register, search and status filtering
- Complaint registration linked to employee ID (no anonymous records)
- Category, priority, involved person/role, description, confidentiality request and evidence filename capture
- Assignment, investigation status and progress notes
- Independent escalation route when Branch Admin / HR is named
- Reports, CSV export and physical filing register
- Print current view

Important limitations:
- Fictional sample cases only.
- Evidence files are NOT uploaded to a server; only the selected filename is recorded in page memory.
- Demo records and changes are held only in browser memory and reset on refresh.
- No real authentication, role permissions, secure complaint vault, email/OTP, notifications, external escalation, database or immutable audit history.
- Production must enforce strict need-to-know access, independent routing, separation of duties, tamper-evident audit trail, secure encrypted attachments, retention/legal hold, anti-retaliation controls and applicable employment/privacy law.
- Complaints concerning Head Office HR or senior management must bypass implicated parties and go to an independent authorised authority or external channel defined by policy.
- This module is not an emergency response channel.
