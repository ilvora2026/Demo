ILVORA Workforce – Head Office Admin Panel
Service 2: Employee Approval & ID Control – Prototype v1

Open index.html in a modern browser.

Included:
- Branch-wise onboarding submission queue
- Search and status filters
- Application review screen with masked illustrative identity data
- Review note required for return/rejection
- Approve / return / reject actions
- Simulated branch-specific permanent Employee ID generation only after approval
- ID formats: ILV-HO-###, ILV-NH-###, ILV-KK-###
- PAN is optional
- Up to 7 uploaded document references shown in sample application records

Important:
This is a front-end demo with sample records only. No real identity data, file storage, employee account creation, OTP delivery, email/SMS, or live database integration is present. Production must implement secure server-side atomic ID allocation, duplicate checks, verified document storage, authenticated approval permissions, audit trails and notifications. Salary remains Administrator-only as previously agreed.
