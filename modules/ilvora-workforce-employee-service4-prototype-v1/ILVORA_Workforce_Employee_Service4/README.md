# ILVORA Workforce — Employee Service 4: My Tasks & Assignments

## Prototype features
- Assigned task summary: to do, in progress and completed
- Task list with status filtering
- Sample task details and assignment metadata
- Employee progress update submission
- Completion and blocked status options
- Recent update history

## Proposed workflow
Task assigner creates and assigns task -> employee receives notification -> employee views task and updates progress -> task assigner reviews completion or blocker -> task is closed or returned.

## Permissions
Employees can view tasks assigned to them and submit progress updates. Reassignment, cancellation, ownership changes and priority changes remain with authorised task assigners unless separately permitted.

## Limitations
Front-end demo with sample data only. No real login, database, notifications, attachments, backend assignment engine, approvals or server-side permission enforcement. Updates are simulated in the browser.

Open index.html in a modern browser.
