ILVORA Workforce – Branch Admin / HR Service 6
Documents & Policy Management – Prototype v1

Open index.html in a modern browser.

Features:
- Employee document register and search
- Document upload form for PDF/JPG/PNG
- Head Office verification decision demo
- Document expiry tracker
- Policies and circulars list with acknowledgement progress
- Physical print/filing register
- Print and CSV export

Workflow:
Branch Admin uploads a document against an existing employee ID and submits it for Head Office verification. Head Office may verify, reject or request clarification. Policies can be listed and acknowledgement progress viewed. The prototype demonstrates screens and local session state only.

Important limitations:
- Fictional sample employees and records only.
- Selected files are NOT uploaded to a server; only the filename is recorded in page memory.
- No real Head Office role enforcement, authentication, OTP, employee notifications, cloud storage, virus scanning, audit service or database.
- Production must implement encrypted file storage, strict role-based access, malware scanning, file type/size validation, audit logs, version control, secure download, retention schedules and legal holds.
- Expiry alerts (60/30/7 days) are recommended but not active.
- Employee policy acknowledgement requires the employee-facing workflow, mandatory acknowledgement, OTP delivery/verification and evidence logging; not live in this Branch Admin prototype.
- Printing must be logged with filing reference. Physical retention and secure destruction must follow the approved HR/legal records schedule.
