Approval is permitted only when the relevant payroll period is closed and locked.

Request verification checklist

  • Confirm employee identity and active employee account.
  • Confirm the requested month and branch.
  • Verify payroll period is approved, closed and locked.
  • Confirm no unresolved payroll correction or data hold.
  • Check whether this is a duplicate or reissue request.
  • Record decision, approver, timestamp and reference.
If payroll is not closed, do not generate a payslip. Keep the request blocked or return it with a clear reason.

Production security requirements

  • Generate only from approved and locked payroll snapshots.
  • Private encrypted document storage; never public file URLs.
  • Authenticated employee access with short-lived, expiring download links.
  • Reissue must create a new version and preserve previous audit records.
  • Notify registered email/app inbox; delivery retries and status logs.
  • Log requester, approver, generated document version, access and download events.
  • Rate-limit requests and prevent cross-employee document access.
  • Apply retention, legal hold and secure deletion policy.
