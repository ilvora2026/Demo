Employee branch assignment

Demo workflow only. In production, branch assignment and transfer require authorised approval and must be linked to the employee's effective date.

Attendance location behaviour

  • Employee's active branch determines the attendance geofence.
  • Check-in and checkout should validate device coordinates against the assigned branch's saved coordinates and radius.
  • Outside-radius attempts should be flagged for review, not silently accepted as valid onsite attendance.
  • Temporary duty at another branch requires an authorised temporary assignment with start/end dates.
  • Branch transfers must update attendance location only from their approved effective date.
A browser prototype cannot verify a phone's real GPS position or prevent spoofing. Production requires authenticated mobile location capture and server-side distance validation.
