Head Office – attendance correction approval queue

Review employee identity, original punch, requested change, reason and supporting evidence. Approval triggers an automatic attendance update and notifications to the employee and Branch Admin / HR.

Non-negotiable controls

  • Only Branch Admin / HR can submit formal attendance correction requests.
  • Only authorised Head Office Admin can approve or reject.
  • No attendance change occurs before approval.
  • Original punch and complete audit history are preserved.
  • Approved correction updates employee attendance and relevant summaries.
  • Employee and Branch Admin / HR are both notified of the decision.
  • Payroll already closed must use a payroll adjustment workflow.
