Stage 2 – Administrator-only fixed salary setup

This stage becomes available after Branch Admin submits the application. Only an authorised Administrator may enter, review, change and save the employee’s fixed salary.

Branch Admin and Head Office users have read-only/no access to salary editing. The salary is linked to the application and, after employee approval and onboarding completion, feeds the payroll calculation automatically.

Production controls: enforce Administrator role on the server and API (not just by hiding the screen); keep previous salary versions, editor identity, timestamp, effective date and reason in an immutable audit log. Payroll should use the active approved salary version and apply configured attendance, unpaid leave, deductions and payroll-period rules.
